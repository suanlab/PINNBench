# docs

## Purpose
Per-paper LaTeX source, build artifacts, and figures for the two research papers cut from this repo (Paper A: early-dynamics routing; Paper C: causal-loss diagnosis) plus their combined/NeurIPS submission variants. Per repo history, standalone paper-draft markdown files were removed from the public tree (see commits "docs: remove paper drafts..." and "docs(README): redact submission-target line"); what remains is LaTeX sources, compiled PDFs/build byproducts, and figure files. This directory is primarily artifacts, not library code.

## For AI Agents

### Working In This Directory
- These are paper-writing artifacts, not application code — there is nothing to import from `docs/` into `src/causal_pinn/`.
- Numeric claims in any `main.tex` here must trace back to an artifact documented in `dataset_pinnbench/MANIFEST.md` / `CLAIM_INVENTORY.md`; if you edit a claim, update those manifests too rather than letting them drift.
- LaTeX build byproducts (`.aux`, `.out`, `.bbl`, `.blg`, `.fls`, `.fdb_latexmk`, `.log`) are present alongside sources; don't hand-edit them — they're regenerated by the LaTeX toolchain.
- Do not reintroduce standalone paper-draft markdown files at the repo root or elsewhere — per repo history those were deliberately removed from the public tree.

### Testing Requirements
Not applicable (no code to test). To validate that figures/claims are consistent with released data, use `make verify-claims` (see `scripts/AGENTS.md`).

### Common Patterns
- Each paper variant directory follows the same shape: `main.tex` + `references.bib` + a NeurIPS `.sty` file + `figures/` + compiled `.pdf` and LaTeX build byproducts.
- Figure filenames are shared/reused across paper variants (e.g. `fig_routing_accuracy.pdf`, `fig_regret_bound.pdf` appear in both `paper_a_routing/figures/` and `paper_combined/figures/`); regeneration scripts are listed per-figure in `dataset_pinnbench/MANIFEST.md`.
