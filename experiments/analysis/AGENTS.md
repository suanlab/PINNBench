# analysis

## Purpose
Generated, derived artifacts consumed directly by the papers: LaTeX table fragments, statistical significance test results, and cross-model "mechanism" figures explaining *why* causal loss and physics weighting behave the way they do. Everything in this directory is produced by scripts in `../scripts/` (chiefly `analyze_mechanisms.py`, `generate_paper_tables.py`, and `statistical_analysis.py`) reading from `experiments/results/`; nothing here should be hand-edited.

## Key Files
| File | Description |
|------|-------------|
| `paper_tables.tex` | LaTeX table fragments (causal ablation, lambda sweep, hybrid comparison, OOD sections) generated by `../scripts/generate_paper_tables.py` from `experiments/results/` JSONs |
| `statistical_tests.json` | Paired statistical test results (means, stds, p-values) generated by `../scripts/statistical_analysis.py`, per `AnalysisSpec` comparison |

## For AI Agents

### Working In This Directory
- Treat every file here as build output: to refresh it, re-run the generating script against `experiments/results/` (after `make fetch-data`) rather than editing the `.tex`/`.json`/`.png` directly.
- `mechanism_figures/` holds PNGs (`*_cross_model.png`, `*_training_trajectories.png`, `*_loss_decomposition.png`) plus `mechanism_summary.json`, all produced by `../scripts/analyze_mechanisms.py`.
- Note the per-paper figure scripts (`../scripts/paper_a_routing/generate_figures.py`, `../scripts/paper_c_causal/generate_figures.py`) write to `docs/paper_a_routing/figures/` and `docs/paper_c_causal/figures/` respectively, **not** here — this directory is reserved for the cross-cutting mechanism analysis and generated tables, not per-paper camera-ready figures.

### Testing Requirements
No tests validate these artifacts directly; correctness is inherited from whatever script regenerated them and the underlying `experiments/results/` data. When claims derived from these files change, re-run `make verify-claims` and the specific generating script, and diff the output against the previous version.

### Common Patterns
- `paper_tables.tex` and `statistical_tests.json` are both keyed off `experiments/results/<name>/results.json`; if a script's output schema changes (e.g. renaming a `condition` or `model_name` field), both generators need updating in lockstep since they use the same `group_field`/`metric_field` conventions.
- Filenames in `mechanism_figures/` follow `<pde>_<figure_type>.png` (e.g. `burgers_loss_decomposition.png`, `kdv_hybrid_cross_model.png`) — keep this convention for any new mechanism figure so `analyze_mechanisms.py` callers can glob consistently.

## Dependencies

### Internal
- Consumes `experiments/results/**/results.json` (via `../scripts/analyze_mechanisms.py`, `generate_paper_tables.py`, `statistical_analysis.py`); has no direct `causal_pinn` library dependency itself (it's data, not code).

### External
- None (static `.tex`, `.json`, `.png` artifacts). The generating scripts depend on matplotlib and NumPy.
